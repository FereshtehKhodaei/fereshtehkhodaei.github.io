Work Project

BPMN-Based Procurement Process Modeling

End-to-End Business Process Analysis and Decision Modeling

Fereshteh Khodaei  |  Work project, 2026  |  Abcheck Co

Overview

An end-to-end BPMN 2.0 model of a Procurement Process, covering purchase requests, validation, inventory and budget checks, supplier evaluation, approvals, purchase orders, goods receipt, and payment.

Approach

The process was progressively modeled by:

  • Decomposing the process into BPMN Tasks
  • Identifying Start, Intermediate, and End Events
  • Modeling decision points using Exclusive Gateways (XOR)
  • Defining responsibilities using Pools and Lanes
  • Modeling Company–Supplier interactions using Message Flow
  • Integrating all components into an End-to-End process model

Result

A structured BPMN model representing:

  • Process flow and activities
  • Decision logic and approval levels
  • Organizational responsibilities
  • Internal and external interactions
  • End-to-End Procurement Process

Outlook

The model provides a foundation for further:

  • As-Is Process Analysis
  • Bottleneck and Handoff Analysis
  • Root Cause Analysis
  • KPI Definition
  • To-Be Process Design
  • Process Automation
